# ProctorIQ

AI-Powered Secure Assessment & Intelligent Proctoring Platform.

## Repository

This repository contains the ProctorIQ web application, an online assessment and intelligent proctoring platform built with Python and Flask.

## Technology

- Python
- Flask
- SQLite
- SQLAlchemy
- OpenCV
- HTML/CSS/JavaScript
- Bootstrap
- Chart.js

## Main Components

- Secure user authentication and role-based access
- Pre-assessment readiness and candidate verification
- Online MCQ assessment workflow
- Browser and face monitoring
- Integrity scoring and violation tracking
- Invigilator dashboard and analytics
- Data analysis and session reporting
